# 리원 보험금 청구 준비

개인정보를 저장하지 않는 범용 청구 준비 체크리스트와 문서목록입니다.

## 다운로드

GitHub Releases에서 `ReOnePartners-InsuranceClaimPrep-Web-v1.0.0.zip`을 내려받고 압축을 푼 뒤 `index.html`을 더블클릭하세요.

## 주요 특징

- PC 3열 · 모바일 1열 반응형 화면
- 이름, 주민등록번호, 계좌번호, 진단명, 사고 상세, 연락처, 실제 파일 입력란 없음
- 체크 상태와 일반 문서 구분은 현재 화면 메모리에서만 임시 사용
- 10분 미사용 시 자동 초기화
- 외부 서버·클라우드·분석 도구·광고 연결 없음
- 사용자가 내보내기를 누르고 확인한 경우에만 텍스트 파일 생성

## 중요한 기능 경계

이 프로그램은 청구 준비를 돕는 일반 체크 도구입니다. 보험금 지급 여부, 청구 가능성, 보장 범위, 지급 제외 사유 또는 제출처별 필요서류를 판단하지 않습니다. 실제 제출 전에는 계약 내용과 공식 안내를 확인하세요.
